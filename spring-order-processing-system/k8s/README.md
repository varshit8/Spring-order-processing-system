# Kubernetes Manifests

This directory contains starter Kubernetes manifests for deploying the Spring Boot microservices.

- `order-service-deployment.yaml` — deployment and service for the Order Service
- `payment-service-deployment.yaml` — deployment and service for the Payment Service

These manifests are a starting point and can be extended with ConfigMaps, Secrets, ingress, and stateful storage for Kafka/PostgreSQL/MongoDB.
